# HOPE — Horizons of Physics Explored

An interactive physics learning project featuring visual simulations such as the Quantum Harmonic Oscillators, Hooke's law and so on 
The frontend uses HTML, CSS, and JavaScript, while backend computations are powered by Python serverless functions on Vercel.

---

## Features
- Interactive wavefunction visualization  
- Quantum state slider (increase/decrease n)  
- Backend computes Hermite-based wavefunctions  
- Fully hosted on Vercel
